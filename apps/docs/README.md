# @sawitsvelte/docs

Documentation site and playground for [sawitSvelte](../../README.md).

SvelteKit 3 + `adapter-static`, fully prerendered. Start it from the repo root with `pnpm dev`
(which builds the packages first, so the docs consume real package output rather than source).

```bash
pnpm dev                                  # from the repo root
pnpm --filter @sawitsvelte/docs build
```
