# Technical debt register

Every entry records a decision, not just a worry. An item stays listed until it is either done or
its trigger is met, so nobody has to re-litigate it from memory.

| #   | Item                                  | Status                    | Decision / trigger                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --- | ------------------------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Automated accessibility scans         | **Done**                  | axe runs per component in Chromium, in light and dark, on every state matrix. Serious and critical violations fail the build. Two meta-tests deliberately break a control to prove the harness still detects failures. Only `region` is disabled, with its reason documented in `tests/support/a11y.ts`.                                                                                                                                                                                                                                                                           |
| 2   | `disabled` vs `loading` semantics     | **Resolved**              | ADR-0007. `disabled` stays native and removes the control from the tab order; `loading` keeps focus, sets `aria-busy`/`aria-disabled`, and blocks activation by cancelling the click.                                                                                                                                                                                                                                                                                                                                                                                              |
| 3   | DOM element ref passthrough           | **Deferred**              | `bind:this` on a component yields the component instance, and no component currently needs the node. Not worth a sixth polymorphism mechanism on speculation. **Trigger:** Phase 3 Dialog must focus or measure its content node. Intended shape: a `ref` bindable prop on root parts only, mirroring where `child` is offered.                                                                                                                                                                                                                                                    |
| 4   | Bundle size measurement               | **Done**                  | `pnpm size` bundles a virtual consumer with Vite + Rolldown, Svelte external, and enforces per-entry gzip budgets. Measured: Button 21.2 kB, Card 20.9 kB, both 21.8 kB gzip.                                                                                                                                                                                                                                                                                                                                                                                                      |
| 5   | Size vs the original budget           | **Open**                  | The architecture's "Button < 2 kB gzip" was written before measuring. Our own component code is 1.7 kB; the rest is shared runtime: `tailwind-merge` ~9.6 kB and `tailwind-variants` ~9.9 kB. Fixed cost, paid once. **Trigger:** before the component count makes the gap matter to consumers — evaluate replacing `tailwind-variants` with an internal helper (~80 lines: base + variants + defaults + slots, no compound variants in use), which would cut roughly 9.9 kB gzip (~47% of the styling runtime). Cost: we own the variant logic and lose tv's inferred prop types. |
| 6   | Duplicate `tailwind-merge` copy       | **Done**                  | `tailwind-variants` bundles its own copy of `tailwind-merge`, so importing both shipped it twice. `cn` now imports `twMerge` from `tailwind-variants` and the direct dependency was removed: 30.9 kB → 21.2 kB gzip.                                                                                                                                                                                                                                                                                                                                                               |
| 7   | Browser test portability              | **Done**                  | Browser tests use an installed Chrome via Playwright's `channel` to avoid a browser download. `SAWIT_BROWSER_CHANNEL=bundled` switches to a Playwright-managed Chromium (after `pnpm exec playwright install chromium`) on images without Chrome.                                                                                                                                                                                                                                                                                                                                  |
| 8   | Changeset tooling                     | **Deferred**              | There is no consumer and no published version to bump yet, so `@changesets/cli` would add workflow without a decision it can inform. **Trigger:** the first npm publish (Phase 5) — at that point every component also gets a stability tier and a migration note policy.                                                                                                                                                                                                                                                                                                          |
| 9   | Source-copy dependencies              | **Documented, by design** | Copying `button.svelte` or a card part also means keeping `cn`, `mergeProps` and `tailwind-variants`. Copy-paste is "own the markup", not "zero dependencies". Stated in ADR-0006 and in the docs.                                                                                                                                                                                                                                                                                                                                                                                 |
| 10  | Accessibility scans for docs examples | **Open**                  | Scans cover components, not the pages that demonstrate them. A docs page can still ship a bad example. **Trigger:** before publishing docs publicly; the `Example` component is the natural place to attach a per-example scan result.                                                                                                                                                                                                                                                                                                                                             |
| 11  | Docs site has no search               | **Open**                  | Two component pages do not need it. **Trigger:** when the component index exceeds roughly a dozen pages.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 12  | Programmatic form submission          | **Accepted limitation**   | `form.requestSubmit()` bypasses the click guard, so a loading button does not prevent a scripted submit. A loading state is a UX affordance, not a security boundary. Noted in ADR-0007.                                                                                                                                                                                                                                                                                                                                                                                           |
